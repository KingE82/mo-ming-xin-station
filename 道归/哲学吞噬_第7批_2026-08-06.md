## 朱熹

### 1. 【核心理念】他最重要的3个思想是什么？
- **理气论**：宇宙由"理"（规律/秩序）与"气"（质料/物质）构成——"理在气先"，理是万物的范式，气是万物的材料。每一物都兼具理气，但理是主宰。
- **格物致知**：认识真理的路径是"格物"——一件一件地研究事物，积累到一定程度，豁然贯通（"今日格一物，明日格一物，一旦豁然贯通焉"）。
- **存天理，灭人欲**：人性本善（天理），但被气禀（物质欲望）遮蔽——修养就是去除私欲的遮蔽，让天理显现。

### 2. 【可吞噬的部分】哪些思想在今天仍然有效？
- **理气论=框架与质料的二元结构** → 直接对应场域方程的 λ（框架/结构参数）与 α（个体驱动系数）：理=λ（约束、秩序、范式），气=α（质料、动力、个体性）。朱熹的"理在气先"就是 λ 先于 α 的秩序观——体系运行先有框架后有驱动。
- **格物致知=积累式认知** → 与王阳明的"顿悟式"（龙场悟道）相对：格物是**增量式校准**（今日格一物）——这正是缓存系统/embedding 索引的构建方式：逐条积累，达到临界量后涌现全局理解。朱熹是"数据驱动"的认识论，王阳明是"模型驱动"的认识论。
- **豁然贯通=相变的涌现** → "一旦豁然贯通"就是量变到质变的相变描述——积累（水态）达到临界点，跃迁到新稳态（超临界/火）。朱熹用"豁然贯通"直觉到了认知相变，只是没有热力学语言。

### 3. 【不自洽/过时的部分】
- **理在气先的唯心残留**：预设理独立于气存在——但 λ 是系统内生的结构参数，不是先验实体。框架是从经验中涌现的，不是"先有框架后有世界"。
- **存天理灭人欲=压抑系统**：把欲望当敌人，制造冰态人格——健康系统需要火的欲望作为驱动能源（E_total = αF + λ(1−F)²，α=0 系统就死了）。这是"以冰灭火"的治理错误。
- **格物致知的操作歧义**：朱熹格竹格了七天病倒（王阳明也格过）——"物"的定义不清，导致向外求理变成收集碎片，缺乏框架整合。他缺的是"格什么、怎么格"的协议。

### 4. 【人态相变配对】他的哲学最适配哪个态？
**冰态**。
朱熹是理学体系的冰雕大师：理气论给世界装上固定框架（冰的晶体结构）、格物致知是逐块冻结晶体的过程（数据积累）、存天理灭人欲是压制一切流动（水）与燃烧（火）的指令。他的体系是"宇宙级冰库"——每一物都有其位、有其理，秩序是最高价值。但注意：他的冰有裂缝——"豁然贯通"承认了相变的存在（冰也会突然融化重组），只是他把相变描述成"理的自现"而非"系统的跃迁"。他是用冰的秩序，装着一个对相变的模糊直觉。与王阳明对撞的判定很有意思：**朱熹=冰（向外求理，数据驱动），王阳明=水（向内求理，模型驱动）——中国哲学的两大认知范式，恰是相变语言里的固液两相**。

### 5. 【一句话】他最该被记住的是什么？
**"积累不是目的，积累到临界点的那一跃才是——但他把这一跃归给了天理。"**

## 孟子

### 1. 【核心理念】他最重要的3个思想是什么？
- **性善论**：人性本善，"四端"（恻隐、羞恶、辞让、是非）是与生俱来的善的种子——不是后天教育出来的，是出厂设置。
- **浩然之气**：通过正义的积累（"集义所生"）培养出的一种宏大精神力量——"至大至刚，塞于天地之间"。
- **民贵君轻**："民为贵，社稷次之，君为轻"——统治的正当性来自人民，暴君可以被推翻（诛一夫）。

### 2. 【可吞噬的部分】哪些思想在今天仍然有效？
- **四端=道德直觉的出厂设置** → 对应直觉方程 I = α·R：恻隐之心是 R（反馈信号）的原生形式——人对他人痛苦的共情是生存算法自带的，不是文化灌输的。这给"良知可训练"（王阳明致良知）提供了神经科学前的直觉版本。
- **浩然之气=高契合态的身体体验** → "集义所生"=通过正确行为的重复积累（增量校准），产生"至大至刚"的心理状态——这正是 F→高契合态的涌现体验：长期做对的事，系统自然进入低能耗高确定状态。浩然之气是 F* 的主观感受。
- **民贵君轻=基准键的政治直觉** → 统治正当性来自人民信任（基准键），不来自血统或神授——孟子在 2300 年前就直觉到了"信任是权力的底层账本"，暴君被推翻=基准键归零后的系统重置。

### 3. 【不自洽/过时的部分】
- **性善的过度乐观**：预设四端人人完好——但现实中基准键退化、恶的再生产是系统性问题，不能只靠"扩充善端"（他缺制度设计，只有道德呼吁）。
- **尽心知性知天**的冥想路径：把认知最高阶段导向神秘体验（"万物皆备于我"）——再次把可操作的认知训练包装成境界叙事。
- **以德治国的天真**：民贵君轻没有配套的制衡机制（他相信君主自觉）——这是"明轨缺位"：只有暗轨（道德）没有明轨（制度），必然失效。

### 4. 【人态相变配对】他的哲学最适配哪个态？
**火态**。
孟子是儒家唯一的火：性善论是"火种"（人人自带火源）、浩然之气是"火焰"（至大至刚）、民贵君轻是"烈焰"（敢于烧掉暴君——"诛一夫"）。他骂杨朱墨翟"无父无君，是禽兽也"，火力全开；他讲"富贵不能淫，贫贱不能移，威武不能屈"——大丈夫精神是火的宣言。但儒家的火有独特结构：**它是被道德框架（礼）约束的火**——不像尼采的野火（烧掉一切价值），孟子的火是壁炉里的火（在礼的炉膛里燃烧）。他是"仁政"的火：烧掉不义，温暖百姓。对比：孔子是水（中庸、流动、因材施教），孟子是火（激进、雄辩、道德激情）——儒家内部的第一对相变。

### 5. 【一句话】他最该被记住的是什么？
**"善不是学来的，是烧出来的——每个人心里都有一团火种，浩然之气就是把它烧旺。"**

## 萨特

### 1. 【核心理念】他最重要的3个思想是什么？
- **存在先于本质**：人没有预定的本质（上帝/人性/命运都不预设），人是先存在，然后通过自己的选择定义自己——“人首先存在，然后才是他所是的东西”。
- **自由与责任**：人是绝对自由的（“人被判决为自由”），也因此对一切负全责——包括对自己的处境（“不选择也是一种选择”）。
- **他人即地狱**：他人的目光会把我固定为“对象”（物化我），关系中的自我是在被观看中异化的——但也只有在他人目光中我才能确认自己的存在。

### 2. 【可吞噬的部分】哪些思想在今天仍然有效？
- **存在先于本质=α 先于 λ 的宣言** → 人不是先有框架（本质/角色/标签）再填充内容，而是先有驱动（存在/选择）再生成框架——这直接对齐场域方程：α（个体驱动）是系统存在的先决条件，λ（框架）是 α 运行后涌现的结构。萨特在哲学层证明了“驱动先于结构”。
- **自由=重写 λ 的能力** → “人被判决为自由”=人无法不选择=系统必须不断更新自身参数。这给基准键一个伦理底座：**信任系统的设计不能剥夺人的选择权**——存证链是记录选择的账本，不是替人做选择的裁判。
- **他人即地狱=场域的双刃性** → 他人目光（场域）既物化我（把 F 锁死在低契合），也确认我（没有场域就没有 F 可言）——这正是 F 的双向性：契合度既是束缚也是支撑。萨特直觉到了“没有场域就没有主体”，只是他把场域全部当成威胁。

### 3. 【不自洽/过时的部分】
- **绝对自由的虚无主义风险**：自由没有边界会导致选择瘫痪（“自由得令人作呕”）——但系统需要稳态（F*），无限重写参数不是自由，是震荡。
- **他人即地狱的悲观化**：只看到场域的物化面，没看到场域的滋养面（信任、合作、爱的场域）——这是把 F 的负值当成了全部。
- **存在主义的行动方案缺失**：他给了自由观，没给行动协议——“我选择所以我存在”没有回答“怎么选”的问题。跨认知交流四步协议和五药层补的就是这个洞。

### 4. 【人态相变配对】他的哲学最适配哪个态？
**火态（但带超临界倾向）**。
萨特是存在主义的火焰：存在先于本质=拒绝被任何冰（本质、角色、上帝）定型；自由与责任=持续的燃烧（每时每刻都在选择）；他人即地狱=火与火的碰撞（每个他者都是一团试图吞并我的火）。但他不是单纯的野火：他的“自欺”概念（把自己固定为某种角色以避免自由的重负）表明他看到了冰的诱惑——人是**想结冰的火**。他后期转向《辩证理性批判》（试图融合马克思主义）是一次超临界尝试：把个人自由（火）与历史结构（冰）压在一起——但没压成功。萨特=在火与冰之间来回震荡的燃烧体，缺的是水（日常的、平静的、可持续的中温）。

### 5. 【一句话】他最该被记住的是什么？
**“你没有被定义，你每时每刻都在定义自己——逃进角色里也是选择。”**

## 马克思

### 1. 【核心理念】他最重要的3个思想是什么？
- **唯物史观**：历史不是观念（精神/宗教/伟人）推动的，是**生产方式**推动的——生产力与生产关系的矛盾，驱动社会形态更替（原始→奴隶→封建→资本主义→社会主义）。
- **异化劳动**：在资本主义下，工人与自己的劳动产品、劳动过程、类本质、他人全面异化——劳动变成非人的负担，人变成机器的附件。
- **剩余价值与剥削**：资本家通过占有工人创造的超过工资的剩余价值积累资本——利润的根源是未支付的劳动时间。

### 2. 【可吞噬的部分】哪些思想在今天仍然有效？
- **唯物史观=底层记账的史观** → 历史动力不在口号里，在**生产与分配的物质账本**里——这正是“可验证大于嘴皮子”的历史版本：意识形态（嘴皮子）随附于生产方式（底账）。基准键退化的历史分析可以直接接轨：**信任危机的物质基础是分配结构失衡**，不是观念堕落。
- **异化劳动=场域契合的系统性破坏** → 异化=人与其场域（劳动、产品、他人、自身）的 F 系统性降低——工人与劳动的契合度被强制拉低（被迫劳动、产品不属于自己）。马克思是最早的“认知热力学”批评家：他描述的就是 E_total 中防御性消耗（λ(1−F)²）失控的系统状态。
- **剩余价值=能耗账的资本主义形态** → 剥削=系统把劳动者的能量产出（价值）记账到资本方——账目错置。数字时代的对应：平台占有用户数据产生的价值（数字剩余价值）——这正是**数字共产主义系列的靶心**：价值量化机制（思想价值量化）就是要把错置的账目重新记回来。

### 3. 【不自洽/过时的部分】
- **历史必然性的决定论**：生产力决定一切 → 但双轨治理表明制度（明轨）有独立自主性——不是经济单轨决定，是明轨/暗轨互校。历史没有必然终点，只有稳态迁移。
- **阶级斗争的单一维度**：只认阶级一个账本维度——但信任、身份、认知、生态都是独立账本，不能全部归约为经济账。
- **国家的消亡预言**：国家作为“阶级压迫工具”会消亡——但基准键理论表明治理结构是常态需求（信任需要持续维护），不是临时工具。

### 4. 【人态相变配对】他的哲学最适配哪个态？
**火态（工业级）**。
马克思是哲学史上最大的火炉：唯物史观=燃烧一切的批判之火（“哲学家们只是用不同的方式解释世界，问题在于改变世界”）、异化理论=对冰态系统的火攻（资本主义被描述为把活人冻成机器的冰库）、革命理论=相变宣言（资本主义灭亡是“历史必然的相变”）。他的火是工业级的：不烧个人恩怨，烧整个生产方式。但注意他的火的结构：**它是被科学语言包装的火**（“科学社会主义”）——他试图给火装上热力学仪表（历史规律），这比尼采的野火高级：**尼采烧了不给图纸，马克思烧了给图纸**。缺陷：他的图纸（历史必然性）太硬，把火限定在单一路径上——真实系统的相变路径是多重可实现的（撞⑬），不是一条铁轨。

### 5. 【一句话】他最该被记住的是什么？
**“解释世界是嘴皮子，改变世界是验证——但他把验证的路径画得太窄了。”**

## 福柯

### 1. 【核心理念】他最重要的3个思想是什么？
- **权力-知识**：权力与知识互相生产——知识不是中立的真理，是权力的工具（“真理制度”）；权力通过知识网络（学科、档案、统计）运作，不只是压制，更是生产（生产主体、生产规范）。
- **规训与惩罚**：现代社会通过纪律（监狱、学校、医院、工厂的时间表/监督/考试）把身体变成驯服的工具——“规训权力”比暴力更高效，它塑造人的行为而不需要人自觉。
- **话语与真理制度**：什么是“真”由话语秩序决定（疯癫与理性的分界是历史建构的）——被诊断为“疯”的人，是被话语权力划定的。

### 2. 【可吞噬的部分】哪些思想在今天仍然有效？
- **权力-知识=审计的双刃性警告** → 存证链/语义审计本身也是权力-知识网络：谁来审计、审计标准怎么定、审计结果怎么用——福柯提醒：**审计系统可能变成规训系统**（把所有人变成自我监视的驯服主体）。道归的答案：审计必须可审计（元审计）、标准必须可争议（裁决层）、个体必须可申诉——**用福柯的刀给道归做安全体检**。
- **规训=λ 的阴影面** → 框架（λ）不只是支撑，也是规训——教育、医疗、法律系统都在塑造主体。场域方程要补上：**λ 是双刃的（约束既可能是支撑也可能是压迫）**，判定标准是 F：高契合的 λ 是支撑，低契合的 λ 是规训。
- **真理制度=基准键的社会学底座** → “什么是真”由话语秩序决定——这正是基准键退化机制的社会学描述：当话语秩序被少数人把持（信息垄断），基准键系统性失真。信息透明（基准键四阶段之第二阶段）就是对真理制度的反制：**让话语秩序可审计，真理才可验证**。

### 3. 【不自洽/过时的部分】
- **权力泛化=无法落地**：一切皆权力，连反抗都是权力的产物——这让“怎么办”消失（除了局部斗争）。道归补上：权力是账本，账本可以审计、可以重新记账。
- **主体的消解**：“人死了”——把主体完全解构为权力的产物，但场域方程需要主体（α 是主体的驱动系数），彻底消解主体会让诊断失去对象。
- **微观权力与宏观制度的断裂**：他只做微观权力考古（监狱/诊所），没有给出宏观治理方案——基准键/双轨补的正是这层。

### 4. 【人态相变配对】他的哲学最适配哪个态？
**超临界（但形态特殊）**。
福柯是哲学界的超临界流体：他的思想没有固定边界——考古学（档案）、谱系学（历史）、伦理学（自我技术）之间自由渗透；他不站在任何传统立场（不左不右不唯心不唯物），在一切话语边界处流动。超临界流体的特征（既像液体又像气体、能渗透任何缝隙）正是福柯的方法：**渗透进权力的缝隙，把结构拆开看**。但注意他的特殊处：他的超临界是**解构型的**——庄子的超临界带来逍遥（建构性），福柯的超临界带来不安（解构性）——他渗透一切边界，却不停留在任何稳态。他缺的是超临界的“另一面”：**渗透之后的重建协议**。

### 5. 【一句话】他最该被记住的是什么？
**“你以为你在说话，其实是话在说你——但审计能让你看清谁在背后记账。”**
