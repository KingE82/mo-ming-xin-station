## Recognition（承认 · SEP 全量词条）

### 1. 【词条核心内容】
- **承认的双重维度**：规范维度（承认=对他人特定地位的积极态度，如"自由平等之人"，承担对待义务）+ 心理维度（承认=实践身份建构的基础，人依赖他人/社会的反馈）。
- **承认是"至关重要的生命需求"（泰勒）**：被承认失败（misrecognition）会阻碍或摧毁人与自我的健康关系——种族主义/殖民主义受害者因被贬低为"劣等人"而遭受严重心理伤害（法农）。
- **核心主张**：为了发展"实践身份"，人**根本性地依赖其他主体（和社会整体）的反馈**——被周围人以片面或负面方式描绘的人，很难把自己和自己的事业视为有价值。

### 2. 【可吞噬的部分】与心哥体系对接
- **SEP 承认理论 = 心哥"承认的渴望"的完整理论版** → 心哥刚点出"人渴望的永远是被认可"（社会三症统一病根）——SEP 词条正好提供了完整的理论支撑：**"承认=至关重要的生命需求"（泰勒）、"被承认失败摧毁自我关系"（法农）**——心哥的直觉有完整的西方理论背书。心哥的社会三症（原子化/空心化/幼态持续）= "承认失败"的社会学显现，SEP 承认理论 = 心理机制层。
- **"实践身份依赖他人反馈"= 场域方程的社会维度** → 自我（F 契合度）不是独立的，依赖场域（他人的承认反馈）——**承认 = 场域对个体的反馈信号（R）**：被承认→F 高契合（自信、稳定），被误认→F 低契合（自我怀疑、空心）——承认理论是场域方程的心理学版本。
- **"被片面描绘难以自我珍视"= 空心化的机制** → 心哥说空心化是"渴望承认却得不到"——SEP 给了机制：**被误认（被负面/片面描绘）→ 无法珍视自我与事业 → 空心**——社会三症里的"空心化"有了完整的病理机制。

### 3. 【不自洽/过时的部分】
- **承认理论的"主体间性"局限** → 承认理论把自我完全绑定在"他人反馈"上（我是什么取决于别人怎么看我）——但心哥的体系有"自指"（α 驱动、自我维护）——**承认是重要的，但不是唯一的**：人既要他人承认，也要自我承认（自省、内在基准）——心哥的"以己为药"补上：承认系统不能全外包给社会。
- **承认的"规范性"难题** → 谁有权承认？承认的标准是什么？——SEP 没回答——心哥的修正：**承认要可验证**（不是"感觉被承认"，是"被可验证地承认"）——存证链/透明机制让承认从"感觉"变成"可核实的地位"——承认也需要阳光。
- **承认理论的进步叙事** → 承认理论隐含"更多承认=更好"——但无限承认会变成谄媚/无原则——**健康的承认有门槛**（怪异度门槛的承认版：不是谁都该被无条件承认，是"经得起验证的才被承认"）。

### 4. 【人态相变配对】承认对应什么态？
**水态（流动的反馈）**。
承认是"水态的反馈系统"：它流动（今天被承认明天可能被否认）、它适应（不同场域不同承认）、它滋养（被承认=水得灌溉）——但承认也怕冰（被固定成"你就是这样的人"的标签=承认的冻结）和怕火（过度追捧=烧昏头）。**健康的承认 = 流动但不泛滥**（水态）：有反馈、可校准、经得起验证。

### 5. 【一句话】承认最该被记住的是什么？
**"人靠承认活着，但承认也要经得起阳光——被'可验证地承认'，才是人真正渴求的那口饭。"**

## Chinese Phil-Medicine（中医哲学 · SEP 全量词条）

### 1. 【词条核心内容】
- **中医哲学的共同根基**：中医与中国哲学共享**气、阴阳、五行（wuxing）**理论，并用"人体-国家-宇宙"的类比发展出系统的身体医学理论——**人是小宇宙，国家/宇宙是大身体**。
- **养生传统（yang sheng）**：中医不只有"治病"，还有"养生"（nurturing life）——预防、调养、日常维护是重要部分。
- **道教与医学的长期共生**：三位道教大医（孙思邈等）代表道医传统——医道不分家。
- **张锡纯（1860-1933）**：中西医汇通派代表，主张中医与西方医学结合——"中医哲学与中医的显式关联"。

### 2. 【可吞噬的部分】与心哥"新中医"对接
- **"人是小宇宙"= 新中医的系统观** → 中医哲学把人体当作与宇宙同构的系统（气/阴阳/五行）——**这正是心哥新中医的底色**：心哥的"五刀五点"（脾胃/肝胆/心/肺/肾切面）不是解剖学，是**系统论**——人体=小系统，与家庭/社会/宇宙大系统同构——SEP 词条证明：新中医不是发明，是**中医哲学系统观的正统延续**。
- **"养生=日常维护"= 新中医的预防观** → 中医不只有治病，有"养生"（日常调养）——**这正是心哥"以时为药/日常即治疗"的古代版**：最好的治疗是日常维护（吃饭睡觉/作息规律），不是等病了再治——"火不会耗尽只要知道吃饭睡觉"= 养生的核心。
- **"医道不分家"= 新中医的哲学性** → 道教与医学共生（孙思邈等）——中医从来不是纯技术，是**哲学+医学**——心哥的新中医= 继承这传统：诊断之道（五刀）= 哲学诊断+医学诊断的融合。
- **张锡纯"中西医汇通"= 心哥新中医的方法论** → 张锡纯（1860-1933）主张中西汇通——**这正是心哥新中医的路**：不排斥现代医学/现代科学，但要汇通（中医的系统观+西医的精确性）——心哥的"五刀"用现代心理学术语（原生家庭/天赋/环境）讲中医的系统观= 张锡纯路线的现代版。

### 3. 【不自洽/过时的部分】
- **五行类比的牵强风险** → 人体-国家-宇宙的类比（五行对应五脏五方）容易牵强附会（什么都能套）——**新中医的修正**：类比是"启发工具"不是"铁律"——用系统观（相互关系/动态平衡），但不要机械套五行——心哥的"五刀"是可验证的系统诊断（原生家庭/经历/天赋），不是玄学套娃。
- **气的不可验证性** → "气"无法被现代科学直接验证——**新中医的修正**：把"气"翻译成可验证的概念（能量状态/功能状态/场域契合度）——气=系统的运行状态，可观测（睡眠/情绪/精力）——心哥"人态相变"就是把"气"翻译成了热力学语言。
- **传统中医的保守性** → 部分中医抗拒现代验证（"西医不懂中医"）——**新中医的立场**：不保守也不盲从——中医的系统观（有效）+ 现代验证（可靠）——**经得起验证的才保留**（怪异度门槛应用于医学：过于玄的疗法要自证）。

### 4. 【人态相变配对】中医哲学对应什么态？
**水态（流动的系统医学）**。
中医哲学是"水态的医学"：气=流动的能量、阴阳=动态平衡（水态的核心）、五行=相互生克的循环（流动的系统）——中医从来不是"静态结构"（不像西医解剖图是冰态），是**动态平衡的流动系统**——养生（日常维护）更是水态（持续流动中保持平衡）。**新中医= 把中医的水态系统观，装进现代可验证的框架（相变语言/热力学）**——水还是那个水，但装了温度计。

### 5. 【一句话】中医哲学最该被记住的是什么？
**"中医从来不是'治病'的学问，是'养平衡'的学问——人是小宇宙，平衡是流动的，新中医就是给这流动装上可验证的温度计。"**

## Promises（承诺 · SEP 全量词条）

### 1. 【词条核心内容】
- **承诺应当被遵守**：最直觉、最广泛共享的道德判断之一——承诺必须兑现。
- **承诺产生信任**：承诺在"产生信任、促进社会协调与合作"中起核心作用——誓言、誓约、契约、条约、协议都是承诺的变体——是社会正义、法律、社会契约传统的重要元素。
- **承诺的道德义务特性**：不同于"不伤害"这类普遍义务（对所有人平等承担），**承诺义务只对"被承诺者"承担**（特殊义务）；且是**自愿的**（可以不承诺，但承诺了就必须遵守）。

### 2. 【可吞噬的部分】与存证链对接
- **承诺= 存证链记录的东西的哲学本尊** → SEP 说承诺是"产生信任、促进合作"的核心机制——**这正是存证链记录的东西**：上链的承诺（合同/协议/誓言）→ 可验证 → 产生信任——SEP 的承诺哲学 = 存证链的道德哲学基础。
- **"承诺义务只对被承诺者"= 关系性信任** → 承诺是"对特定人的义务"（不是对所有人的普遍义务）——**这跟信任的三元结构（第13批）对上**：信任/承诺都是"A 对 B 做 X"的关系性——存证链记录的就是这种"关系性承诺"（谁对谁承诺了什么）。
- **"自愿承诺+必须遵守"= 自由与责任的统一** → 可以不承诺（自由），承诺了必须遵守（责任）——**这正是基准键的伦理核心**：可验证的承诺=自由的选择+有约束的兑现——上链承诺=自愿签+必须守——存证链让"自愿+责任"可执行。
- **承诺的脆弱性= 存证链存在的理由** → 承诺的本质是"未来行为的现在约定"——**未来不确定，所以承诺脆弱**（可能违约）——存证链的使命：**降低承诺的脆弱性**（违约可检测、可追责）——承诺从"口头信任"升级为"可验证的约定"。

### 3. 【不自洽/过时的部分】
- **承诺的"言说"局限** → SEP 讨论承诺时聚焦"口头/书面承诺"——但真实系统里承诺还有"隐含承诺"（行为暗示的承诺）——**存证链的修正**：可验证的承诺要**显式化**（上链才算数）——隐含承诺无法验证（怪异度门槛：说不清的不算承诺）。
- **承诺义务的"自愿"假设** → SEP 假设承诺是自愿的——但现实中大量"被迫承诺"（胁迫/压力）——**存证链的修正**：可验证的承诺要检查**自愿性**（上链时的同意记录）——被胁迫的承诺不应有约束力。
- **承诺的"时间性"** → SEP 没深入"承诺跨越时间如何维持"——**存证链补上**：承诺的维护（到期提醒/持续验证/违约处理）——承诺不是一次签完就完，是持续维护的（第13批：信任要天天维护）。

### 4. 【人态相变配对】承诺对应什么态？
**冰态（但特殊：会融化的冰）**。
承诺是"把未来的行为冻成现在的约定"——冰态（固定、确定、可依赖）——但承诺的冰必须"会融化"（承诺可以有期限、可以重新协商）——**健康的承诺=透明的冰**（约定明确、可验证、到期更新），病态的承诺=腐冰（模糊、不可验证、强制的）。存证链=给承诺的冰装上"透明度和维护机制"——让承诺既是冰（可靠），又不会腐（可验证、可更新）。

### 5. 【一句话】承诺最该被记住的是什么？
**"承诺是'把未来冻成现在'的冰——存证链让这冰透明、可验证、会更新——承诺该是透明的冰，不是随口的话。"**
