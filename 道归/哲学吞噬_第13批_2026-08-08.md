## Trust（信任 · SEP 全量词条）

### 1. 【SEP 词条的核心内容】
- **信任的双重性**：信任重要（让我们依赖他人——爱、建议、帮助），但也危险（信任涉及风险——对方可能辜负我们）。如果有保证对方一定兑现，就不需要信任了——**信任的本质是"无保证的依赖"**。
- **信任何时有根据（warranted）**：词条主线问题是"信任在何时是合理的"——三个维度：合理（justified，基于好证据）、有根据（well-grounded，确实瞄准了可信之人）、可行（plausible，条件存在）。
- **信任的三元结构**："A 信任 B 去做 X"（Hardin）或"A 把珍视之物 C 托付给 B"（Baier）——不是"完全信任某人"，而是**特定领域、特定事项的信任**。
- **信任的两个条件**：能力（competence，B 有能力做 X）+ 动机（motivation，B 愿意做 X）。
- **动机论之争**：风险评估派（信任=感知风险低，不区分信任与单纯依赖）vs 动机性质派（动机的"性质"重要——B 是因为在乎我才做，还是因为利益才做——这区分了信任与依赖）。

### 2. 【可吞噬的部分】与基准键的对接
- **"无保证的依赖"= 基准键要消灭的东西** → SEP 说信任=无保证的依赖（有保证就不需要信任）——但基准键定理的反转：**"保证"可以被工程化**——存证链不是消灭信任，是**把"无保证的依赖"变成"有验证的依赖"**：你仍然依赖（对方可能违约），但违约可检测、可追责、可记账——**信任从"盲目"升级为"可验证"**。SEP 的"信任危险论"是基准键要解决的第一问题。
- **信任的三元结构= 存证链的字段设计** → "A 信任 B 做 X"（Hardin）——这正是存证链的记账格式：**主体(A) + 对象(B) + 事项(X) + 条件(C)**——不是模糊的"我信任你"，是精确的"我信任你做X，条件C下"——基准键的语义审计就是三元结构的工程化。SEP 的哲学分析直接给出了存证链的数据模型。
- **能力+动机= 审计的两个维度** → 信任需要 B 有能力（competence）+ 有动机（willingness）——对应审计协议：**能力维度可验证（B 有没有做过类似的事=行为记录）、动机维度难验证（B 为什么愿意做）**——基准键的边界：存证链验证"能力+行为"，动机留给"声誉+激励"（暗轨）——**这正是明轨/暗轨的分工：明轨管可验证的行为账本，暗轨管不可验证的动机声誉**。
- **信任与依赖的区分= 基准键的精确性** → SEP 争论"信任 vs 单纯依赖"（动机性质派）——基准键的回答：**不区分**——因为基准键不看"你信不信"，看"行为可不可验证"——动机不可验证，行为可验证——**基准键把"信任的哲学难题"转化为"行为的工程问题"**。

### 3. 【不自洽/过时的部分】
- **"有保证就不需要信任"的预设过时** → SEP 预设"保证"与"信任"互斥（有保证→无信任）——但现代系统证明：**保证（验证）不是信任的替代，是信任的基础设施**——你信任银行不是因为你盲目相信，是因为有监管、审计、法律保证——**可验证性不是信任的敌人，是信任的脚手架**。SEP 的"信任=无保证依赖"定义是前现代版本。
- **人际信任范式的局限** → SEP 说人际信任是主导范式（制度信任、政府信任都要建模于人际信任）——但基准键反了：**制度信任（可验证的）才是主导范式，人际信任是它的退化版本**——人际信任=没有存证链时的临时替代（靠脸熟、靠名声），制度信任=有存证链时的正式形态。SEP 的范式倒置了。
- **动机性质之争的学院自限** → 争论"动机的性质是否重要"（在乎 vs 利益）——但基准键：**动机不可验证，争论无意义**——重要的不是"他为什么做"，是"他做了没有、能不能验证"——**把不可验证的问题从系统设计中删除**。

### 4. 【人态相变配对】信任最适配哪个态？
**水态（动态平衡）**。
信任是典型的水态现象：信任需要流动（死信=冰，冻结的信任是控制的假象）、需要适应（不同领域不同信任度）、需要温度（太冷=怀疑一切，太热=盲目信任）。SEP 说信任是"无保证的依赖"（水态的冒险）——但基准键给信任装了"验证的温度计"：**信任不是全有全无（冰/火），是动态调节的（水）**——存证链让信任可以在"水温"上精确调节：证据强→温度升，违约→温度降。**基准键=给信任装上恒温器**。

### 5. 【一句话】Trust 词条最该被记住的是什么？
**"信任不是无保证的依赖，是保证不足时的临时依赖——可验证性不是它的敌人，是它的脚手架。"**

## Game Theory（博弈论 · SEP 全量词条）

### 1. 【SEP 词条的核心内容】
- **博弈论的定义**：研究"相互作用的理性选择如何产生结果"——每个参与者的最优行动取决于对其他参与者行动的预期，反之亦然——**结果可能是任何参与者都未曾意图的**（"看不见的手"式的涌现）。
- **历史**：冯·诺依曼+摩根斯坦（1944）首次数学化；但博弈论思想古已有之（柏拉图《拉凯斯篇》中苏格拉底回忆德里昂战役——士兵面临"跑还是不跑"的博弈：无论胜负，跑都是个人最优，但大家都跑则必败——**最早的囚徒困境雏形**）。
- **核心概念**：纳什均衡（没有参与者能通过单方面改变策略而获益的状态）、囚徒困境（个人理性导致集体非理性）、重复博弈（长期互动改变均衡）、可信承诺（commitment）、共同知识（common knowledge，见下条）。

### 2. 【可吞噬的部分】与基准键的对接
- **"结果可能不是任何人的意图"= 系统的涌现性** → 博弈论承认：个体理性行为的聚合可能产生无人想要的集体结果（囚徒困境）——这正是基准键退化机制：**每个人都理性自利，集体却滑向信任崩塌**——基准键要解决的就是"个体理性→集体非理性"的涌现问题：通过制度设计（明轨）改变博弈结构，让个体理性与集体理性对齐。
- **纳什均衡= 基准键要打破的僵局** → 纳什均衡描述"谁都不愿意单方面改变"的稳定状态——但很多纳什均衡是**帕累托劣**的（如囚徒困境的背叛均衡）——基准键的目标：**通过可验证性把均衡点从"劣均衡"迁移到"优均衡"**——当背叛可检测、可追责（存证链），背叛的代价上升，合作成为新的均衡——**基准键= 用信息结构改变均衡位置**。
- **重复博弈= 存证链的博弈论原理** → 重复博弈中，合作可以成为均衡（因为背叛会被惩罚，未来的合作价值>眼前利益）——存证链的本质：**把单次博弈变成重复博弈**——每次行为都被记录，等于"无限次重复博弈"——背叛者无处可逃，合作者积累声誉——**存证链是重复博弈的工程实现**。
- **可信承诺= 承诺的验证问题** → 博弈论的核心难题：如何让对方相信你的承诺（廉价谈话问题）——基准键的回答：**承诺上链=可验证承诺**——不是"我承诺"（口头，不可信），是"我承诺+违约可检测+违约有代价"（上链，可信）——存证链把"廉价谈话"升级为"昂贵承诺"。

### 3. 【不自洽/过时的部分】
- **完全理性假设的局限** → 经典博弈论假设参与者完全理性——但真实系统里人有认知偏差、情绪、有限理性——基准键不假设完全理性，只假设"可验证性"：**不需要你理性，只需要你的行为可被记录**——用结构约束替代理性假设。
- **信息不对称的默认** → 博弈论默认信息不对称（我不知道你会不会背叛）——基准键的修正：**通过透明化减少信息不对称**（明轨的信息透明阶段）——不是默认信息不对称然后博弈，是**先改变信息结构再博弈**——基准键在博弈之前就改了博弈的规则。
- **单次博弈的贫困** → 很多经典结果（囚徒困境）依赖单次博弈假设——但现实是重复博弈（社会是持续互动的）——基准键直接用"无限重复博弈"视角（存证链=永远的记忆），绕过单次博弈的悲观结论。

### 4. 【人态相变配对】博弈论最适配哪个态？
**冰态（结构分析）**。
博弈论是"冰态的科学"：它把互动关系建模为固定的策略结构（策略集、收益矩阵、均衡点）——把流动的人际互动冻成可计算的矩阵。它的力量来自冻结（可计算），局限也来自冻结（假设固定）。但注意：**纳什均衡是"冰态的相变点"**——均衡=系统暂时稳定的状态（冰），但外部参数变化（引入可验证性）会触发相变（均衡迁移）——基准键就是**给博弈论注入"可验证性"这一温度参数**，让系统从"劣均衡冰"相变到"优均衡冰"。博弈论的冰态结构+基准键的温度参数=完整的"博弈热力学"。

### 5. 【一句话】Game Theory 最该被记住的是什么？
**"博弈论把互动冻成矩阵，但忘了给矩阵装上'可验证性'这个温度参数——均衡不是宿命，是可以相变的。"**

## Common Knowledge（公共知识 · SEP 全量词条）

### 1. 【SEP 词条的核心内容】
- **公共知识的定义**：命题 A 是公共知识 = 所有人都知道 A，且所有人都知道所有人都知道 A，且所有人都知道所有人都知道所有人都知道 A……**无限递归**（"我知道你知道我知道……"）。
- **区分公共知识与共同知识**：共同知识（mutual knowledge）= 每个人都知道 A（但不知道别人知不知道）；公共知识（common knowledge）= 每个人都知道 + 每个人都知道每个人都知道……（无限层级）——**公开宣布**是把共同知识变成公共知识的关键（"彼得告诉我他要迟到"的公开声明让所有人都知道所有人都知道）。
- **公共知识支撑社会生活**：夫妻在商场走散能找到彼此（都知道对方会去咖啡吧=公共知识）；行人闯红灯造成拥堵（缺乏对信号状态的公共知识）——**协调成功的条件=公共知识，协调失败的原因=公共知识缺失**。
- **历史**：休谟（1740）最早提及相互知识在协调中的作用；刘易斯（1969）《惯例》首次完整哲学分析；奥曼（1976）给出数学定义（事件的不交集划分）。

### 2. 【可吞噬的部分】与基准键的对接
- **公共知识= 基准键"可验证"的认知定义** → 基准键的"可验证"不只是"我知道这是真的"，是"**我知道你知道我知道这是真的**"（无限递归）——**存证链的核心价值不是记录事实，是创造公共知识**：上链=公开宣布=把"我知道"变成"所有人都知道所有人都知道"——**存证链是公共知识的工程实现**。
- **"公开宣布"的力量= 信息透明的原理** → SEP 说"公开宣布把共同知识变成公共知识"——这正是基准键四阶段之"信息透明"的认知论基础：**透明不是把信息给大家看（共同知识），是让大家知道大家看到了（公共知识）**——公开透明的威力在于无限递归的确认：我知道公开了，你也知道公开了，我知道你知道……——信任建立在公共知识上，不是共同知识上。
- **协调失败= 公共知识缺失** → 行人闯红灯造成拥堵=缺乏对信号状态的公共知识——**基准键退化的机制：不是信息不存在，是公共知识破裂**——信息可能还在（共同知识），但"大家知道大家知道"的链条断了（公共知识崩溃）→ 协调失败→ 信任崩塌——**基准键退化= 公共知识的层级断裂**。
- **刘易斯《惯例》= 规范/暗轨的认知基础** → 惯例（convention）是公共知识支撑的协调模式——**社会规范（暗轨）的本质= 公共知识支撑的预期结构**："我知道你会守礼，你知道我会守礼，我们都知道……"——暗轨的认知底座是公共知识，明轨的认知底座是公开规则——**双轨的认知基础都是公共知识**（暗轨靠惯例形成，明轨靠制度宣布）。

### 3. 【不自洽/过时的部分】
- **无限递归的理想化** → 现实中没有人能真正完成"无限层级"的推理（认知负荷）——但公共知识的"无限"是理想极限，实际系统用"足够层级"近似——存证链的公开性让"足够层级"变得便宜：**公开记录让递归层级几乎自动达成**（不需要每个人推理，只需要每个人能看到公开记录）。
- **共同知识/公共知识的二分过简** → 现实中存在中间态（我知道你知道，但不确定你知道我知道）——基准键不纠结层级，只问：**是否公开、是否可验证、是否可追溯**——公开记录把层级问题变成工程问题。
- **公共知识的静态性** → SEP 把公共知识当作"已达成状态"——但真实系统的公共知识需要**持续维护**（公开记录需要持续更新、验证需要持续运行）——基准键的"维护"思想补上：公共知识不是一次达成的，是天天维护的。

### 4. 【人态相变配对】公共知识最适配哪个态？
**冰态（但特殊：透明的冰）**。
公共知识是"透明的冰"：无限递归的确认=把共识冻结成所有人都看到的晶体结构（冰的透明性）——但它是"会自我更新的冰"：公开记录持续更新（冰在流动中保持透明）。**公共知识的相变意义：共同知识→公共知识的跃迁=一次公开相变**——当信息从"各自知道"（分散的水）变成"大家都知道大家知道"（透明的冰），系统状态发生了质变（协调成为可能）——**公开宣布是相变触发器**。基准键的信息透明= 制造这场相变。

### 5. 【一句话】Common Knowledge 最该被记住的是什么？
**"信任不建立在'我知道'上，建立在'我知道你知道我知道'上——存证链就是无限递归的工程实现。"**

# 第13批 · 弹药汇总（整合进对撞文档）

| 词条 | 态 | 给体系的弹药 |
|---|---|---|
| Trust（信任） | 水态 | "无保证的依赖"=基准键要消灭的东西（存证链把盲目依赖变成可验证依赖）；三元结构=存证链字段设计（A信任B做X）；能力+动机=审计两维度（明轨管行为账本、暗轨管动机声誉）；信任vs依赖之争=基准键直接删除 |
| Game Theory（博弈论） | 冰态 | 涌现性=基准键退化机制（个体理性→集体非理性）；纳什均衡=要打破的劣均衡（可验证性改变均衡位置）；重复博弈=存证链原理（单次变无限次）；可信承诺=上链承诺（廉价谈话→昂贵承诺） |
| Common Knowledge（公共知识） | 冰态（透明的冰） | 可验证的认知定义=无限递归（存证链创造公共知识）；公开宣布=信息透明的原理（透明是让大家知道大家看到了）；协调失败=公共知识层级断裂（基准键退化机制）；惯例=暗轨的认知底座 |

**新增对撞弹药（基准键的西方对照组·三大支柱齐活）：**
- **SEP 信任词条 vs 基准键定理**：SEP 问"信任何时合理"（哲学问题），基准键答"信任怎么可验证"（工程问题）——**哲学两千年没解决的信任难题，基准键用存证链绕过去了**（不解决"何时该信"，只解决"如何验证"）
- **"保证不是信任的敌人，是信任的脚手架"**：SEP 预设信任=无保证依赖，基准键反转：可验证性=信任的基础设施（银行信任=监管+审计+法律）
- **范式倒置**：SEP 说人际信任是主导范式，基准键说制度信任（可验证的）才是主导范式——人际信任是制度信任的退化版本（没有存证链时的临时替代）
- **存证链=重复博弈的工程实现**：博弈论说重复博弈改变均衡（合作成为可能），存证链把单次博弈变成无限次重复博弈（每次行为都被记录）——**纳什均衡不是宿命，是可相变的**
- **基准键退化=公共知识的层级断裂**：不是信息不存在（共同知识还在），是"大家知道大家知道"的链条断了（公共知识崩溃）——修复基准键=修复公共知识层级（公开+可验证+可追溯）
- **双轨的认知统一**：暗轨靠惯例（刘易斯：公共知识支撑的协调模式），明轨靠制度宣布（公开规则）——**双轨的认知基础都是公共知识**，只是形成机制不同（惯例演化 vs 制度宣布）
- **信息透明的精确定义**：透明不是"给大家看信息"（共同知识），是"让大家知道大家看到了"（公共知识）——基准键四阶段的"信息透明"= 制造公共知识相变
- **给博弈论装上温度参数**：纳什均衡=冰态相变点，可验证性=温度参数——劣均衡冰→优均衡冰的相变=基准键的治理目标
